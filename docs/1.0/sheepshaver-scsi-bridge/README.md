# SheepShaver SCSI Network Bridge

**Status:** Planning
**Feature Branch:** `feature/sheepshaver-scsi-bridge`
**Milestone:** TBD

## Overview

Network SCSI backend for SheepShaver that bridges to scsi2pi over TCP, enabling MESA II (and other vintage SCSI software) to communicate with real Akai hardware via a Raspberry Pi.
