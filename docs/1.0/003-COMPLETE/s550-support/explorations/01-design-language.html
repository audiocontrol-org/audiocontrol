§ 02 · Typography

Reading measure · 36rem

Readable measure for in-editor docs, error-state copy, About / Help panels, and any future longform. Lines settle around 60–72 characters at the editor's body size, which keeps eyes moving without head-swivel.

§ 08 · CRT Monitor

CRT monitor — the device's actual screen

Every editor page shows the S-330/S-550's video-out display in a persistent right-sidebar dock. The CRT is content — the device's live screen state — not editor chrome. Atmosphere (subtle phosphor cast, scanlines) is intentional inside this panel because it's reproducing a real CRT. Atmosphere does not bleed into the editor's chrome elsewhere.

§ 09 · Direction

Direction recap

Locked operator decisions that ground every per-page mockup that follows.

01 · Theme

Dark only

Matches audiocontrol.org's color-scheme: dark. The white-background editor migrates to a deep blue-cool ink. s330-* tokens stay as identity but their on-surface assumptions are recalibrated for dark backgrounds.

02 · Fonts

Self-hosted woff2

Departure Mono · IBM Plex Sans · JetBrains Mono. /fonts/*.woff2 with preload + preconnect. No CDN runtime dependency.

03 · Brand contract

Third editor-roland brand

Defined in oletizi/audiocontrol.org/src/sites/editor-roland/brand.ts. Shares typography + spacing with audiocontrol; overrides only colors.primary to s330 blue. The editor consumes this brand via the same BrandColors / BrandTypography / Brand interfaces.
