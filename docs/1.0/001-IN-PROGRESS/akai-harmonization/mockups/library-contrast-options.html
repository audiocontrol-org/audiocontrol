Library contrast + selection — three directions

Each variant shows the same disk-tree + device-memory panel pair, with one item selected in the DISK view only (the memory view shows its previous selection ghosted out to demonstrate the single-selection-across-panels contract). Operator picks one; the chosen variant becomes the production palette + selection treatment.

A · AA-grade muted + accent-tint selection
Muted text deepened to #3a3528 (~7.5:1 on cream — comfortably above WCAG AA). Selection = accent-tinted background fill + 3px accent left-border. Matches the .ac-list-row[aria-current] pattern already used on Programs / Samples / Keygroups lists, so the library page becomes consistent with the rest of the editor.
