§ 02 · Operations

Library operations

Each launcher opens a SlideDrawer. No centred-modal dialogs; no toolbar above the tree. Object-level CRUD is colocated with the affected node — these launchers cover whole-library operations.

01 / 06 · Save

Save current set…

Snapshot the working device state into a new set on disk. Names, descriptions, target folder.

02 / 06 · Load

Load selected set…

Restore the highlighted set into the device. Memory map preview, conflict detection, dry-run option.

03 / 06 · Import

Import patches / tones / samples…

Bring in individual objects from another set. Slot picker, allocation preview, segment auditing.

04 / 06 · Export

Export patch / tone / set…

Write a single patch, tone, or full set out. Optional WAV bundle for downstream tools.

05 / 06 · Folder

Create / rename folder…

Organise the directory. Folders contain other folders or sets; no depth limit beyond filesystem.

06 / 06 · Delete

Delete folder / set…

Confirm-and-purge. Uses the shared ConfirmDialog primitive — no hand-rolled centred modal.
