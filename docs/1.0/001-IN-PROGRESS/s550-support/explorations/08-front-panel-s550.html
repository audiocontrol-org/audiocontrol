S-550 — Rack-Strip Front Panel

The S-550 is a 2U rack-mount sampler (the S-330 is a desktop module). This mockup renders the virtual front panel as the hardware it stands in for — a 19" rack strip with brushed-aluminum chassis, amber-backlit graphic LCD, numeric keypad, and an arrow diamond with INC/DEC value keys. Distinct from the S-330's portrait floating widget; same interaction contract via useFrontPanel.pressButton(...).

Honors v3 design language: Departure Mono for button labels, JetBrains Mono for the LCD glyph grid, IBM Plex Sans for the annotation prose. s330-* blue identity preserved. Red used only for the REC LED, per feedback_rec_led_accent.

Form Factor

2U rack strip — proportion 5.43 : 1 matches Roland's 19" × 88.9 mm chassis spec. The S-330's existing VirtualFrontPanel.tsx is a 280 px portrait widget; the S-550 inherits a wider landscape footprint as the visual differentiator. Same drag/expand/collapse behavior; different layout.

Keypad Cluster

Left zone — 4 × 3 grid: digits 0-9, decimal, plus EXIT / CMD / ENT / BS as cluster-corner functions. The S-550's numeric keypad is the primary distinguisher from the S-330 (S-330 has no keypad); every direct slot/value entry routes through here.

Graphic LCD

Center zone — 320 × 80 amber-backlit graphic LCD with scanline overlay and warm radial glow. Renders the S-550's Edit/Mode/Menu screens; same surface that VideoCapture shows for the real device, but software-rendered for the virtual panel.

Navigation Diamond

Right zone — arrows at cardinal positions + accent-filled EXEC center. Mirrors the S-330 nav idiom (existing NavigationPad.tsx) so the useFrontPanel.pressButton('nav-up'|…) contract applies unchanged. Stacked INC/DEC to the right reuses ValueButtons.tsx.

Function Row

Six function keys above the diamond — MODE / MENU / SUB / COM / EDIT / EXEC. Same shape as the S-330's FunctionButtonRow.tsx; EDIT is S-550-specific (S-330 surfaces edit via MENU + arrows). Keyboard shortcuts F1-F6 carry over.

Status LEDs

Right rack ear — vertical strip: POW (green), MIDI (amber, blink on rx/tx), REC (red, device-active only per feedback_rec_led_accent). The red dot is the homage; never used for danger or error in the panel surface.

Chassis Texture

Brushed-aluminum face via repeating-linear-gradient grain + 12% → 88% lightness ramp. Hairline rules separate the three zones. Rack-ear screws are SVG-less CSS radial gradients with cross-head slots — pure CSS, no asset dependency.

Interaction Contract

Every <button class="key" data-emit="…"> maps to a FrontPanelButton in the React component. Click → useFrontPanel.pressButton(emit) → simulated or real-device SysEx out. Visual :active state mirrors hardware press; data-active="true" is the controlled override for keyboard-driven presses.
