Troubleshooting
  • Connect your S-330 using a MIDI interface.
  • Choose MIDI ports matching your interface or S-330.
  • Allow SysEx permission when prompted.
  • S-330 displays IDs 1–17 but protocol values are 0–16.

Direction B · Signal-flow diagram

Frames the connect task as a physical signal-flow diagram. The operator sees the three nodes (this app → interface → device) and the MIDI signal bus connecting them. The form fields live INSIDE the relevant node — MIDI ports inside the interface, Device ID inside the device. The connection is the diagram coming to life.

Strengths: teaches the operator the mental model of the connection, not just the UI. Errors can be surfaced on the affected node. Visual feedback when signal flows (animate the bus line).

Trade-offs: wider than the other directions; doesn't fit narrower viewports without restacking. Some operators just want a form and a button; the diagram might feel like ceremony.
