If you're having trouble connecting…
  • Make sure the S-330 is powered on and connected via your MIDI interface.
  • Input and Output should be the SAME interface in most setups.
  • If the browser asks for SysEx permission, allow it — required for full device control.
  • The S-330's front panel shows IDs as 1–17 but the protocol value is 0–16. The form here uses the front-panel value.

Direction C · Single focus card

Brutally minimal. One card, one task, one button. Everything else — transport selector, refresh ports, help — is demoted to small footer links or a disclosure. The page surface around the card is quiet so the operator's gaze lands on exactly what they need to do next.

Strengths: impossible to miss the next action. Renders well at any viewport (the card just centers and the footer links wrap). Easy to extend with a connecting/error state on the same surface (red border → accent fill on Connect, state badge in the header swaps).

Trade-offs: no spatial / device metaphor — the operator just sees a form. The "transport selector" disclosure is hidden enough that someone running a non-Web-MIDI transport (HTTP server, etc.) may not find it without a hint.
