# S3000XL Editor

**Status:** Planning
**Feature Branch:** `feature/s3000xl-editor`

## Overview

Web-based editor for Akai S3000XL sampler programs, keygroups, and sample zones. Communicates via MIDI SysEx over Web MIDI. Built as a new `akai-s3k-editor` module with shared UI primitives from `editor-core`.
