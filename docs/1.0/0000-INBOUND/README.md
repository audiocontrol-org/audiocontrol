# Inbound Feature Ideas

This directory holds feature ideas that have not yet been accepted into the roadmap.

## Purpose

Features here are proposals under consideration. They may be:
- Rough ideas needing refinement
- Features waiting for prioritization decisions
- Concepts requiring feasibility assessment

## Lifecycle

1. **Inbound** — Feature idea is proposed here
2. **Accepted** — Move to `000-PENDING/` when accepted into roadmap
3. **Rejected** — Delete or move to `004-ARCHIVE/` with rejection notes

## What Belongs Here

- Initial feature sketches (doesn't need full PRD)
- Problem statements without solutions
- User requests needing investigation
- Ideas from codebase exploration

## Moving to Accepted

When a feature is accepted:

1. Create full documentation (PRD, workplan, README)
2. Move directory to `000-PENDING/`
3. Update ROADMAP.md Feature Index
