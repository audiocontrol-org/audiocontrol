# S3000XL Library Page Conformance

**Status:** Planning
**Feature Branch:** `feature/s3k-library-page`

## Overview

Bring the Akai S3000XL editor's library page into conformance with the UI/UX standard established by the Roland S-330/S-550 editor. Adds a three-column layout with device memory panel, drag-and-drop between device and library, sample import/export via MIDI SDS, and program/multi import/export via Akai SysEx.
